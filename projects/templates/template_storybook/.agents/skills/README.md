# Skills

Project-local skills for the `template_storybook` exemplar. Each skill folder
ships `SKILL.md` (YAML frontmatter with `name` and `description`), `AGENTS.md`
(skill contract), and `README.md` (orientation). The full operating walkthrough
is [template-storybook/SKILL.md](template-storybook/SKILL.md); see
[AGENTS.md](AGENTS.md) for the directory contract.
