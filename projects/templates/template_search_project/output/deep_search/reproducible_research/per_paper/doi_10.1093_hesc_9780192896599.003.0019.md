## Abstract

This chapter argues for making data and scripts open and accessible. It explains that making code and data available will improve the integrity and progress of science, and this is worthwhile for researchers in all disciplines and at all career stages. Computer scientists and professional programmers most often use a system called git to keep track of changes within the code. Then the chapter considers how to interface with platforms called Git Hub, R Markdown, and Open Science Framework. The common data sharing issue of data acquisition devices' proprietary native file format can be solved by either converting the data to a standard format or converting the data into a generic data format that is not specific to a particular scientific field or data type.
