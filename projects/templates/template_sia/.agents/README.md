Agent-facing scaffolding for the `template_sia` exemplar: a project-local
skill catalog under [`skills/`](skills/).

- [`AGENTS.md`](AGENTS.md) — technical reference and update rules

  (when-to-use guidance, quick reference commands, pitfalls)

Load the skill when working inside this template; see
[`skills/README.md`](skills/README.md) for the catalog.
