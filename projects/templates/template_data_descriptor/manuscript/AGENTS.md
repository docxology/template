# manuscript - AGENTS.md

Keep prose claims tied to `data/example_descriptor.json` and the tested
`src/data_descriptor/` package (`descriptor.py`, `figures.py`, `verification.py`).
Do not transcribe volatile numbers into prose; cite the artifact that produces
them.

Figures are embedded with real paths and labels, for example
`![Schema overview](figures/schema_overview.png){#fig:schema_overview}`, and must
correspond to real files under `figures/` generated by
`scripts/generate_figures.py`. A registry entry whose generated file is absent is rejected at validation. A config-only figure registry entry does not
render. That gate has its own expected-fail control: a deliberately incomplete render set must be rejected before the registry can publish. — every figure needs a real embed block (the fail-closed registry
publisher rejects missing PNG files: see `tests/test_registry.py`'s
missing-file rejection case). Claims stay bound to dataset
structure, schema, provenance, license state, byte-level integrity, and
release-readiness evidence; never to empirical effects in the synthetic data.
