# AGENTS.md — docs/ for template_data_descriptor

Agent-facing notes for this documentation tree. The nearest authoritative
contract is [`../AGENTS.md`](../AGENTS.md); monorepo-wide rules live in
[`../../../../AGENTS.md`](../../../../AGENTS.md). Decision-memory and
verifier-hardening rules (negative controls for verifier-like gates) follow
the monorepo `docs/rules/memory_and_decision_records.md`.

## Layout

- `src/data_descriptor/` — descriptor schema, verification, registry, and
  figure-data logic. See `src/AGENTS.md` and `src/README.md`.
- `scripts/` — thin orchestrators only; business logic belongs in `src/`.
- `tests/` — zero-mock suite; `test_verification.py` carries checksum/row-count
  mismatch negative controls; `test_registry.py` covers the registry contract.
- `manuscript/` — `manuscript/AGENTS.md` is authoritative for token, figure,
  and bibliography rules in that tree.

## Conventions observed in this repo

- Every quantitative manuscript claim is produced by the tested library and
  regenerated by the scripts; nothing is hand-entered (see
  `manuscript/00_abstract.md`).
- Verifier-like gates (validation, checksum verification) always pair with a
  negative control.
- Keep volatile numbers generated, not transcribed into prose.
- Never hand-edit `output/`; regenerate through the pipeline.

## How docs here are maintained

- Keep this tree short and factual; one file per concern.
- Measured counts belong in the monorepo's generated
  `docs/_generated/COUNTS.md`, not here.
