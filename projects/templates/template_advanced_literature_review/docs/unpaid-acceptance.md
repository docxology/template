# Bounded unpaid phase acceptance

The offline phase fixture remains the default and this exemplar remains
unpublished. The additional command tests its source-declared `retrieval`,
`screening`, `local-classification`, and `licensed-fulltext` capabilities with
unpaid network services and an explicitly selected installed local Ollama model.
It acquires no paid API, model, credentials, DOI, deposit, or publication.

From the repository root:

```bash
uv run python projects/templates/template_advanced_literature_review/scripts/_run_unpaid_acceptance.py --mode core
uv run python projects/templates/template_advanced_literature_review/scripts/_run_unpaid_acceptance.py \
  --mode live --model llama3.2:1b --endpoint http://127.0.0.1:11434 \
  --output-dir output/.pipeline/literature_acceptance/a-fresh-run
```

`core` inspects the committed reference corpus and reports no live execution;
the normal fixture/analysis scripts retain the complete offline route. The
underscore-prefixed acceptance orchestrator is excluded from automatic analysis
discovery. Live execution requires the declared platform SDK, Python 3.12–3.14, installed
project dependencies including `pypdf`, and an already available loopback Ollama
service containing the selected model.

The bounded lane runs the first configured query for each declared phase (up to
three phases), using that phase's enabled Crossref engine and at most three
CC-BY-4.0-filtered records per query by default (explicit ceiling five). It retains
the real deterministic filters, deduplication, dependencies, memberships,
overlaps and citation diagnostics. Existing phase-artifact manifests are checked
against the freshly generated bytes, and an independent ID-set calculation
checks cross-phase membership. This scope does not execute every configured
query or satisfy campaign-size, citation-quality, or systematic-review gates.

Four real model calls classify the four held-out synthetic screening cases in
`data/llm_filter_calibration.json`; the existing domain threshold requires at
least 0.75 accuracy. This tests declared filter behavior rather than validating
scientific inclusion decisions. One actual model call per phase classifies a
retained abstract using the declared study-type vocabulary and an exact source
quote. Empty retained phases or absent substantial abstracts remain blocked.
The maximum is seven generations; exact quotations prove custody, not entailment
or domain correctness.

One retrieved record must also supply substantial full text for its exact DOI.
A publisher PDF requires an active deposited CC-BY-4.0 license for its matching
content version; Europe PMC XML must embed that license and the selected DOI.
Unknown rights or unavailable full text is blocked. Raw source/extraction bytes,
license evidence and complete independently parsed BibTeX are retained. Abstracts
and fixture text cannot replace full text. The scope is license-filtered and
bounded, so its sample must not be represented as an exhaustive empirical review.

Fresh ignored run directories retain HTTP/redirect receipts, phase manifests,
exact model requests/responses, stable installed-model digest, token ceilings,
and `receipt.json`. Source custody covers the actual imported meta-analysis
dependency as well as local producers, all public platform Python and root
package/lock metadata. Loaded-code and installed runtime identity are checked
across workers and before receipt promotion. Request process deadlines are at
most 60 seconds; the run budget is at most 600 seconds and late runs cannot pass.
Historical output bytes and the unpublished lifecycle remain unchanged.

Exit `0` requires every declared producer. Missing unpaid services/models or
exhausted deadlines return `75`; failed calibration, malformed/partial producers,
fabricated quotes, invalid phase provenance, and custody drift return `1`. Tests
use real loopback HTTP/process conformance oracles with synthetic responses;
these do not count as actual external-provider and installed-model acceptance.

Actual implementation custody distinguishes a source checkout from an installed
platform wheel. Checkout evidence includes public infrastructure/scripts and root
package/lock files; wheel evidence instead binds installed public Python, the
selected distribution's METADATA/RECORD, its exact declared file set, and the
selected runtime. Workers start with a fresh owned bytecode prefix before imports,
audit actual executed module code against held source and execution-time cache
bytes, and recheck custody before promotion. Standalone startup seeds the actual
already-running main frame before business imports; this compares compiled code
fields and does not recover original comment bytes. Configuration consumers parse
the exact immutable bytes admitted at freeze time, including hypotheses and
classification where those are declared; reopening a changed snapshot cannot
change the consumed config. Its persisted snapshot is still verified at promotion.
No absent checkout lock is fabricated inside a wheel. The project declares the
platform SDK dependency in `pyproject.toml`; standalone execution installs an admitted platform wheel
and the exemplar wheel into the selected environment.
