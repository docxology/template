# Agent Skills

This directory carries the Agent Skills bundle for the advanced multi-phase
literature-review exemplar. It follows the shared exemplar convention:

- [`AGENTS.md`](AGENTS.md) — per-template agent contract catalog
- [`skills/`](skills/) — repository-scoped skill definitions
- [`skills/template-advanced-literature-review/SKILL.md`](skills/template-advanced-literature-review/SKILL.md) — the operating walkthrough for working inside this exemplar

Load the skill before changing retrieval, evidence, manuscript, or rendering
behavior in this project.
