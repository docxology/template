# Project-local skills

Each skill folder contains a frontmatter-bearing `SKILL.md`, a folder-level
`AGENTS.md`, and a human-facing `README.md`. Names must be unique across the
repository's public skill discovery roots.

- [`AGENTS.md`](AGENTS.md) — skills directory contract
- [`template-advanced-literature-review/`](template-advanced-literature-review/) — the exemplar's operating skill (`SKILL.md`), its contract (`AGENTS.md`), and the human pointer (`README.md`)
