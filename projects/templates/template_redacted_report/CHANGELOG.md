# Changelog

## Unreleased (2026-08-02)

Publication-pass enhancements: additional organization-specific release
policies, deterministic exemplar figures, manuscript-to-audit binding tests,
and documentation completion.

### Added

- Organization-specific release-review policies in `src/redacted_report/redaction.py`:
  `law_enforcement_release_policy`, `public_records_release_policy`,
  `health_privacy_release_policy`, and the `declared_release_policies()` registry —
  all invented fixtures, all exported from the package facade.
- Deterministic exemplar figures (`src/redacted_report/figures.py`):
  `redaction_flow` and `disclosure_control_matrix` PNGs with accessible SVG
  companions and a label-keyed `figure_registry.json`, generated by the new
  allowlisted Stage 02 script `scripts/02_build_figures.py`.
- Tests: `tests/test_taxonomies.py`, `tests/test_figures.py`,
  `tests/test_manuscript_binding.py` (audit-schema fail-closed, measured-table
  binding, figure-reference resolution, Stage-02 allowlist binding).
- `CHANGELOG.md` and `docs/` (design-decision reference).

### Changed

- `_redaction_coverage` derives sensitivity from the policy's public-ceiling
  rank instead of a hardcoded `UNCLASSIFIED` literal, so non-intelligence
  policies measure coverage correctly.
- `matplotlib` added to the project dependencies; SVG figure ids pinned via
  `svg.hashsalt` and the live `<dc:date>` metadata line stripped for
  byte-deterministic regeneration.
- `manuscript/config.yaml` (and the forkable example) now run
  `02_build_figures.py` in the normal Stage 02 order after the canonical
  artifact writer.
- `manuscript/config.yaml.example` paper date synced to the live config.

## 0.1.0 — 2026-07-10

Initial public release of the redacted-report exemplar: a formal redaction and
release-review template covering classification ceilings, source-control
markings, authority, redaction ledgers, reviewer approvals, residual-risk and
mosaic-risk checks, a sixteen-variant visual proof matrix, steganographic
provenance, and optional Kmyth TPM sidecar sealing.

### Added

- Disclosure-control audit engine (`src/redacted_report/redaction.py`) with
  bounded redaction reasons, source-control coverage, mosaic-risk scoring, and
  review gates.
- Typed fixture loading and deterministic, text-free public projections
  (`src/redacted_report/artifacts.py`): `redaction_audit.json` and
  `release_ledger.json`.
- Visual proof matrix (`src/redacted_report/visuals.py`, `profiles.py`,
  `_proof_renderer.py`): four redaction styles × four PDF backgrounds with
  steganography and optional Kmyth TPM sidecars.
- Canonical Stage 02 analysis (`scripts/01_generate_release_artifacts.py`),
  dev-variant generation/verification scripts, and the 90%+ coverage test
  suite.
