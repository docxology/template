## Fixed this session

**M1 (Medium) — unbounded subprocess in shell-wrapper integration tests.**
`tests/integration/test_run_sh.py::run_script` and
`tests/integration/test_secure_run_sh.py::run_script_cmd` called
`subprocess.run` with no `timeout`. In a cold environment `run.sh`
auto-installs uv via pinned installer script (measured: >60-90 s), so all 7
wrapper tests failed by pytest-timeout with no subprocess teardown; once the
uv download cached, the same tests passed. Fix: explicit `timeout=300` on both
call sites.
Verification: `uv run pytest tests/integration/test_run_sh.py
tests/integration/test_secure_run_sh.py` -> **12 passed**; ruff clean on both
files.
