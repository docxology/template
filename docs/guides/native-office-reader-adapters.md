# Native Office and EPUB reader adapters

`native_office_observer.convert_office` executes LibreOffice Writer or Impress
headlessly with a fresh private profile against exact admitted DOCX/PPTX bytes.
`observe_office_layout` rasterizes every converted page and observes independent
source obligations. `native_epub_observer.inspect_epub` executes EPUBCheck
through an explicitly selected actual Java runtime, then Calibre's
`ebook-convert`. Tool absence raises `NativeToolUnavailable`; package parsing
cannot replace native execution.

The caller provides a fresh private evidence directory, sanitized environment,
original finite deadline, and run identity. Version probes, original exits,
input/output hashes, and executable hashes are retained. EPUBCheck requires an
explicit reviewed JAR and actual runtime `bin/java` with its `release` identity.
The complete runtime and bundle JAR set are bound before and after execution.
Manifest class paths must stay inside that bundle. The actual validator consumes
private copies of admitted JAR bytes, preserving dependency paths. Java injection
variables are removed; Calibre uses private configuration/cache directories.
These adapters install nothing and use no interactive application session.
Calibre uses the documented Qt software-rendering diagnostic
[`QTWEBENGINE_CHROMIUM_FLAGS=--disable-gpu`](https://doc.qt.io/qt-6/qtwebengine-debugging.html).
Its exact private environment is retained before execution and independently
validated during portable replay.
Every producer job and fresh supervised EPUB suite shares one frozen private
bundle across all scope/cell observers; callers pass its directory through
`inspect_epub(..., frozen_engine=...)`. Each child binds
every consumed JAR and original runtime before and after execution. Portable
`replay_epub_conversion` reopens only admitted retained artifacts, validates
all original command receipts and runtime/JAR identities, and reparses the actual
reader PDF. It never reopens an original external producer runtime path.
Archive closure includes the common consumed JAR paths once, with every cell's
unchanged path/SHA reference retained. Per-cell copies must not consume or expand
the aggregate evidence archive budget.

Projection contracts must be rebuilt from frozen source by both producer and
reader. The projection observer requires every native page and exact 150-dpi
raster, checks ordered duplicate text occurrences, clipping, localized visible
ink, role-specific font floors, source page geometry, and actual citation/QR
hyperlinks. QR values are decoded from actual admitted raster pixels by
`zbarimg`; a missing decoder remains unavailable, while its recognized original
no-symbol exit is a failed visual observation. Links cannot replace QR decoding.
QR observation retains version and native loader receipts plus the actual linked
scanner core bytes, binding that core before and after decoding independently of
the CLI executable. Repeated PDF resource references are deduplicated as an
inventory; every actual image draw is still checked and an extra draw fails.

A figure requires frozen source bytes and source-derived destination geometry.
Its complete decoded RGB pixels must match an actual native PDF image, with the
native image box within the declared geometry tolerance. Localized raster
comparison additionally checks visible projection. Lossy native recompression
fails exact source-image fidelity; a coarse image score cannot hide a changed
chart digit. Alpha images require a declared compositing policy and remain
unsupported by this observer.

EPUB spine checking compares every ordered OPF spine body against independent
source chapter contracts, including any cover/title/navigation spine entries.
No `linear="no"` entry is silently excluded. Complete native reader-PDF checking
maps ordered source occurrences through all actual pages and raster regions.
Unsupported scientific or nontext source projections retain explicit blockers.

The supervised control APIs run fresh valid native baselines before specific
mutants, retaining actual child original exits and native receipts. Projection
controls cover numeric mutation, clipping, tiny type, opaque overlay, citation
mutation, changed image pixels, single-pixel source mutation, image distortion,
and QR mutation/occlusion. Office controls produce real DOCX/PPTX packages and
convert them with LibreOffice; EPUB controls require both EPUBCheck success and
real Calibre reader execution before their intended semantic/layout diagnostic
counts. Setup exceptions, missing tools, malformed packages, and timeouts cannot
stand in for the intended negative result. CSS or OOXML mutations count only
when the actual selected native engine exposes the required diagnostic.
The Calibre clipping control expects missing source glyphs: its reader discards
characters outside the page. Native PDF projection controls independently check
retained glyphs crossing the crop boundary.

Conversion and a narrow source observation do not independently establish full
format acceptance. The central acceptance worker and strict reader must bind
source reconstruction, complete scientific/nontext obligations, all variants,
and actual supervised controls before clearing their respective gates.

## Scientific source coverage and independent references

`native_office_semantic_source.observe_office_semantic_source` reconstructs the
shared combined edition from admitted source snapshots and runs two genuine
Pandoc parses. The first runs before filters or citeproc, so the independent
`native_office_source_coverage.office_coverage_obligations` census retains every
Math, Table, Cite, Image, RawBlock and RawInline occurrence. The second consumes
the production filter and bibliography order. Both original processes, AST
bytes and source custody are retained. These records prove source parsing;
they do not admit native scientific layout.

A complete scientific reference requires the following bounded stages. Until
all stages have independent native witnesses, each census occurrence remains
an explicit unresolved obligation.

1. Rebuild reference DOCX or EPUB exclusively from ordered source Markdown,
   source configuration, variables, bibliography, source-bound figure bytes
   and reviewed filter/runtime bytes. Freeze metadata, resource paths and the
   original writer command before execution. Candidate packages, combined
   derivatives, PDFs and producer-generated TeX cannot supply reference input.
2. Read both native packages through genuine Pandoc and independently account
   for every source occurrence. Preserve table cell order, spans and contents,
   citation display and target identities, equation content and figure assets.
   A canonicalization needs its own source-to-native proof; identical omission
   by both writer runs cannot discharge an occurrence.
3. Convert the frozen reference through the same reviewed native reader and
   compare all pages, glyphs, font observations, vector geometry and rendered
   pixels with the candidate. Native equality supplements occurrence coverage.
   It does not replace it. Source image pixels and intrinsic geometry remain
   separate requirements, because identical reader downsampling can otherwise
   conceal shared detail loss.
4. Obtain independent TeX/native truth for mathematical and raw constructs
   whose package representation differs or disappears. Raw page breaks require
   actual section pagination; raw tables and equations require source content
   and geometry witnesses. Unknown raw languages or unsupported constructions
   remain blocked rather than being normalized away.
5. Supervise genuine changed, omitted, reordered, hidden, table-cell, equation,
   citation and figure mutants. Preserve original process exit codes, admitted
   global deadlines and runtime custody. Portable replay recomputes the source
   census and reference from its own relocated source snapshot.

The finite algebra PDF observer currently covers only its declared proven
subset. Its availability does not establish complete DOCX/EPUB mathematical
coverage. The full scientific reference stages above remain implementation and
native-control obligations; current plain-text native controls do not stand in
for their completion.

The source-only package and full projection stages are implemented separately:

  font attributes, line/rectangle/curve geometry, decoded embedded-image streams
