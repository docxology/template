# Independent scientific PDF references

The source-only reference is supplementary evidence. It does not admit a complete
scientific document or replace the existing unsupported-source findings.

`native_format_pdf_source.observe_pdf_source` rebuilds the ordered manuscript
from current source after verifying hydrated provenance. Its actual Pandoc JSON
receipt precedes citeproc and preserves original Math and Cite identities. The
scientific reference consumes this admitted AST, current configuration and declared
preamble, rather than the rendered manuscript's TeX, PDF, bibliography output or
auxiliary files.

`native_format_scientific_math.observe_scientific_math_reference` retains every
Math occurrence, including headings, notes and table cells. It independently
builds the actual source template and interprets mathematical commands through
XeTeX with an explicit XeLaTeX format. Shell escape is disabled and private TeX
configuration directories isolate the reference. Discovery and fresh final
compilation preserve original process receipts, finite budget and measured time,
source AST and implementation bytes, consumed XDV and logs, FLS inputs, and the
native backend's successful file opens. Font files must be observed by the actual
backend: XeTeX FLS alone omits those dependencies. The dependency set and bytes,
source and native executables must remain unchanged through final execution.

The native comparator reads interpreted glyph identities, fonts, relative
geometry and complete 150 dpi page pixels. `native_format_math_anchors` separately
requires exact adjacent source prose for each native interval. Missing, expanded
or ambiguous anchors remain unsupported. The current finite anchor seam does not
resolve citation expansions, raw commands, cross-reference labels, line-break
hyphenation, table typography or layout directives. Source math hidden inside raw
TeX requires a separate complete ledger; it cannot be silently excluded from the
AST Math accounting. Fraction and radical vector boundaries, colors, every-page
layout and portable replay remain obligations of the complete admission gate.

Retained local development observations include genuine complex inline summation,
fraction and exponent plus display integral reference readback; original tools
exited zero. Independently compiled exponent and display-number mutants fail
source identity. A valid white-ink math mutant preserves native glyphs but fails
visibility and pixel comparison. A separately rendered full-source fixture passes
math and adjacent prose anchors; changed prose fails the anchor comparison.
These component observations do not constitute acceptance of the public roster.
