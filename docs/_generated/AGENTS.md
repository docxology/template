# docs/_generated — technical guide

## Purpose

This directory holds **generator output** plus **maintainer-written** index files (`README.md`, this `AGENTS.md`). Retained dated snapshots are historical evidence. Other generated files below are overwritten by their named generator; do not edit any of them by hand. **`COUNTS.md`** is machine-generated by `scripts/docgen/counts.py` and gated by `counts.py --check` in CI and pre-commit (see [`README.md`](README.md)).

## Conventions

- Link to [`active_projects.md`](active_projects.md) for the public CI/documentation project scope; avoid copying local `discover_projects()` rosters into other guides.
