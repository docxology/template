# Release-note custody

Versioned notes must match root package metadata and describe verified source
behavior. Release workflows publish them only after every required exact-source
acceptance gate passes. Generated overview art communicates architecture and
update themes; it is not a test receipt, scientific result or certification.
Keep its source asset and descriptive alternative text. Preserve the original
generated image in the task workspace. User-approved illustrative PNGs have an
exact path exception in the large-file hook; no general binary exception exists.

See [README.md](README.md) for versioned notes.
