publication.

## Explicit minor preparation

The coordinated metadata planner keeps exact next-patch preparation as its default.
Selecting `--release-kind minor` prepares the same major, exactly the next minor,
and patch zero. The checked v2 plan binds that selection through application and
retained rollback. It updates the root SDK and declared compatibility bindings
without resolving third-party dependencies or advancing exemplar own versions.
Metadata preparation does not authorize a tag or release.

## Strict execution and evidence boundaries

Auxiliary readers bind the original operation deadline and preserve failed
observations. Source checkouts and installed distribution metadata are assessed
in their own dependency planes. Active Inference avoids duplicate preliminary
work while retaining strict artifact hydration and fixed-point validation.
Isolated diagnostic children suppress bytecode writes into held environments.

Combined-PDF failures retain the first TeX error context, when present, alongside
the final log tail. The native citation regression requires a successful render
and resolved bibliography content; a partial PDF cannot satisfy the test.

Structured generation uses bounded fields and exact quote choices from consumed
source before the original strict parsers run. The declared native lane pins
`smollm2:360m` and authenticates its model bytes. Advanced screening controls are
synthetic filter-behavior checks, not held-out scientific evaluation. Search and
Advanced preserve configured discovery scope, citation completeness and strict
licensed full-text consumption; a metadata record alone never establishes
successful full-text retrieval or scientific support. Complete HTML
ClientChallenge signatures are classified as blocked provider responses; original
bytes remain retained and the existing licensed full-text fallback remains strict.
Meta workflow generation assigns unique positional node IDs and preserves the
parser's dependency and exact-quote checks.

Prose selects the installed SDK in an isolated interpreter before admitting its
pre-import audit roots. Formal supports explicit external receipt destinations
with readable final parents and held no-follow traversal. Default Registered figure
production writes figures and their registry under `output/`, preserving
manuscript source images. The declared Meta provider action builds the genuine
wheel from an independent project copy with the locked Root backend, so packaging
metadata stays outside the held source checkout.

Audited acceptance launchers suppress bytecode writes during isolated Python
startup, including `.pth` imports, until the existing Source audit admits a fresh
private cache. The public Source/cache checks and exact auxiliary payload
readback remain in force.

Active Inference omits its unused `pytest-benchmark` dependency and storage
option, avoiding plugin startup that refreshes the held Git index during
discovery. Changed/missing compiled-source controls reuse the genuinely settled
fixture baseline and retain both regeneration branches, physical composition
checks and strict validation.

Prepared test runtimes require the core runner stack without requiring unused
benchmark tooling. Shared parallel commands omit the optional benchmark flag
while preserving explicitly selected benchmark dependencies and behavior.

Project runtimes honor exact core runner versions declared in their own `uv.lock`,
with exact workspace supplements for undeclared core packages. Malformed or
ambiguous locks and version conflicts still refuse admission. Provider probes
suppress bytecode writes; audited test children enable them only after admitting
a fresh private cache.

## CI work and retained originals

[Root lane controls](../../tests/infra_tests/project/test_root_case_lanes.py) and
[runtime controls](../../tests/infra_tests/project/test_root_runtime_v2.py) build
fresh real test roots without first executing an unused positive lane. The
positive lane fixture and the runtime cohort still execute their genuine cases
and validate their lifecycle. CI dispatches historically longer contracts first
while preserving canonical shard IDs, complete modules and acceptance deadlines.
The dispatch weights are advisory observations.

The required acceptance workflow retains complete installed/runtime CLI stdout,
stderr and original exit codes as artifacts beside their receipts. Large outputs
remain available without filling job logs, and original failures still fail their
steps.

The vendored font decoder retains its original byte pin with a single-file
EOF-hook exception. Generated output statistics and Markdown validation summaries
stay local and ignored, keeping canonical publication artifacts within the
unchanged repository output budget.

## Readable publications with complete local fonts

Publication producers preserve full DOI text, correct corpus denominators and
figure labels, and improve table wrapping, pagination and boundary markers.
The shared web-font transport packs every original bundled face into one local,
deterministic LZMA stream. The loader bounds the stream before decoding and
checks each face's original byte count and SHA-256 before loading it. Font
licenses travel with the script; no remote font request is required. The raw
font bundle and legacy loaders remain supported.

inputs and the declared own-lock environment. Rerun changed gates with their
declared profiles; retain unchanged original measurements with their measurement
revision, date, runtime and input provenance. Record current-input verification

release-intent note grants no acceptance or publication result.
