# 5.0.0 — release notes

Cut from the `v5.0.0` tag. The tagged commit is the merge of the release-train pull request that
carries this note: `c5af32a18560ca12267484b182a94b826b47cf47` (the merge of `#215`, itself the
`#207` merge `63f77fcbfabe4a472222806b890f092c909729fb` plus the release-surface corrections),
followed on `main` by `#204`, `#212`, `#213`, `#216` and `#219`, and by the platform admission,
the incorporated native fixes, the residue fixes and the strengthened gates ending with the commit
that carries this note (this line).

## What this release changes

- **Native inventory sharding seam.** Per-cell transport artifact naming for every
  kind, with `cell=None` keeping the previous names byte-identically, and a union
  gate that counts cells rather than shards.
- **Sidecar link-sync consolidation.** Four linking modules unified.
- **Publication gate selection policy.** `--changed` narrowing is admitted only for
  evidence that cannot reach another project's publication output, and an
  observation failure raises rather than guessing a clean change set.
- **Diagnosability.** A native refusal now names why it refused instead of
  discarding the reason.
- **Platform 5 admission.** The release guards admit platform 5, and every canonical
  exemplar's publication binding moves to 5.0.0 with its tracked copy and manifest.
- **Native repairs, residue fixes and the gates around them.** The whole-PDF control
  ceiling, the deadline and verdict guards, the retained preflight refusal reason, the
  installer console-script shim exemption, the declared-capacity reclaim, and the checks
  that now refuse a stale version on `CITATION.cff`, a release note's first heading, the
  release index, the root prose surfaces, an exemplar's platform binding, its lock rows
  and its artifact manifest.

## What this release does not claim

`native Source reference lacks strict published rendered evidence` was never a
content blocker: the predicate was correct and the receipts were behind it. The
strict published-rendered-evidence gate stays in force and unchanged. The fifteen
exemplars whose publication copies moved to platform 5.0.0 were re-rendered and
re-receipted; the remaining ten were rebound to their unchanged output bytes under
the current stage closure; all twenty-five now pass the gate. The value of this
release is that the instruments tell drift from missing content, rather than
reporting silence.
