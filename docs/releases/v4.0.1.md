# Research Project Template 4.0.1

![Template 4.0.1 repository and update overview: configure, test, analyze, render, validate and publish; a shared Python SDK, 25 public exemplars, source and runtime identity, native witnesses, portable artifacts and exact release bytes.](https://github.com/docxology/template/releases/download/v4.0.1/template-v4.0.1-overview.png)

`template/` is an open-source platform for reproducible research. A shared Python
SDK supports 25 independently versioned public projects. The pipeline connects
configuration, tests and analysis to PDF, HTML, DOCX, EPUB and slide deliverables.
Python 3.12, 3.13 and 3.14 remain the supported runtime matrix.

**Release intent: 2026-10-10.** This date and version are frozen for final-source
acceptance. They do not establish a published release. The prepared 4.0.0
candidate was not published; the preceding published root release is v3.8.0.

## Acceptance and publication

These notes and the illustration describe source behavior and the intended
update. They do not assert that final local, hosted, native, installed, export,
transfer or publication gates have passed. Freeze the complete source tree and
commit before final-revision acceptance; later source changes require affected
evidence to be renewed. Health, coverage floors, no-mocks, hooks and the complete
required acceptance remain in force.

The [local CI and release command map](../maintenance/ci-local.md) is the single
starting point for choosing a development check or the required release route.
Focused passes and diagnostic batches provide feedback; publication requires
fresh final-source acceptance and the exact authenticated hosted artifact.

The planned root assets are the admitted wheel, source distribution, this image
and `template-v4.0.1-artifacts.json`. The release body must identify the accepted
commit, hosted run/artifact and aggregate receipt hash. Each public exemplar
retains its declared destination, independent version and required source,
export, remote, tag, asset and deposit receipts.
