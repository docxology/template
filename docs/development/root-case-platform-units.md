# Required Root case platform units

Applicability is distinct from capability availability. Every explicitly reviewed family remains in the complete census and full policy, and retains all Python 3.12–3.14 targets. A family with no platform-kind obligation applies to both globally required platforms. Source-reviewed platform-kind prerequisites may narrow that family's applicable target set; their intersection must remain nonempty. Missing tools, credentials or providers cannot narrow applicability. Supported targets outside the current host remain required cells.

The deterministic partition groups each exact family and parameter member by its declared lane and applicable platform tuple. Complete-target units preserve the primary lane identity; narrower units have stable identities such as `core:darwin`. Unit selection resolves the exact source-required member set and never accepts caller exclusions. Every family occurs in exactly one unit. The unit's required cells enumerate every applicable platform and all three supported runtimes, with complete nodes, obligations and policy SHA. An empty/unknown/contradictory platform declaration refuses compilation; it cannot waive a case.

The lane producer resolves unit IDs through the full independently admitted policy/census. Core/live mode checks use the unit's actual base lane. Wrong-host units report blocked rather than skipping or counting their cases as passed. Provider/tool availability still blocks applicable units when unavailable. Readback resolves the same exact member selection from current source.

This partition compiles reviewed scope; it does not establish that a platform declaration is scientifically justified. Independent review must verify the actual platform predicates and supported behavior before installing the full production policy. The genuine-census tests explicitly label altered applicability rows as contract partition experiments, retain every actual case, and prove that provider availability cannot remove other required platform receipts.

Required runtime/profile wiring must require every emitted cell and authenticate each selected minor in its own actual audited interpreter. A parent running Python 3.14 cannot reconstruct Python 3.12 runtime/provider custody as equivalent. Missing source-owned production policy or unverified required cells remain blocked/unknown; source integration does not establish a complete release.
