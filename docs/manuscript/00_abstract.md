# Abstract

The Research Project Template provides a shared pipeline for preparing
research software, manuscripts, and publication artifacts. Infrastructure
defines stages and evidence contracts. Individual projects own their
analysis, tests, manuscript source, and output configuration. This methods
manuscript traces how a project directory resolves to authored manuscript
sections, how rendering consumes project artifacts, and what validation
records about the result. It uses the repository's resolver, stage
entry points, and validation contracts as evidence for the described
behavior.
