# Infrastructure manuscript status

The [local methods manuscript](README.md) describes the architecture and
operating contracts of the root infrastructure repository. The renderer uses
this directory as the project source when the root checkout is registered
explicitly. Public exemplar projects under `projects/templates/` keep their
own manuscripts and publication metadata.

The 2026-08-29 documentation audit initially recorded this directory as a
status marker. The source added here follows the root manuscript scope in
[the standardization issue](https://github.com/docxology/template/issues/344).
The earlier publication cited in the repository
[CITATION.cff](../../CITATION.cff) remains available under its own DOI.
