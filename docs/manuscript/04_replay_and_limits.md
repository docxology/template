# Replay and limitations

To replay the infrastructure manuscript, prepare a locked renderer
environment, register a clean project checkout under a qualified working
name, and run the render and validation stages. This manuscript uses
a checked-in diagram staged into the project-local figures directory.
Projects with numerical claims need their own analysis outputs, input
versions, and tests before generating a manuscript that uses those
values [@template-source].

The local replay checks the relationship between one source revision and
its rendered artifacts. It does not measure research productivity or
establish that external readers can reproduce the results of every
exemplar. Publication workflows add separate identity, provenance, and
authority requirements. The earlier paper's DOI identifies that publication
and does not identify this local build [@friedman2026template].
