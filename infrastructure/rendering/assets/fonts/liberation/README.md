# Liberation font assets

These unmodified Liberation 2.1.5 font bodies are distributed with their
[SIL Open Font License text](OFL.txt). [provenance.json](provenance.json) records
each filename, body hash, font metadata and the license text normalization.

Keep the license and provenance with the fonts. Rendering and native validation
must verify their actual selected files and observations through the existing
source-bound font contracts.
